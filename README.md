# 雾野列车 (Mistvale Journey)

一款致敬《风来之国》(Eastward) 的像素风 RPG 剧情冒险游戏，融合"2D 塞尔达"式探索解谜要素。
纯 HTML5 Canvas + 原生 JavaScript 实现，零依赖，浏览器直接运行。

## 启动方式

1. 双击 `index.html` 直接游玩；或
2. 本地服务器：`node server.js` 后访问 http://localhost:8090

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| J 轻点 | 普通攻击（洛恩：平底锅挥击 / 小芽：能量泡泡） |
| J 长按 | **蓄力攻击**（洛恩：360° 旋风斩·伤害2·强击退 / 小芽：巨型穿透泡泡·麻痹3秒） |
| K / X | 切换角色（分头行动时：切换操控，另一人原地待命踩板） |
| E / 空格 / 回车 | 交互 · 对话 · 用钥匙开锁门 |
| ESC / I | 暂停菜单 → 设置（音乐/音效 开关+音量调节） |

## 游戏简介

瘴雾侵蚀大地，人类退入地下石门镇苟延残喘。
沉默的矿工洛恩在矿道深处救下白发女孩小芽——她体内沉睡着能净化瘴雾的「芽光之力」。
隧道塌方的那一夜，两人踏上古老的东行列车，去寻找传说中被雾海淹没的「晴原」。

### 核心玩法（2D 塞尔达要素）

- **双角色机制**：随时切换洛恩（近战输出）与小芽（远程控制），共用血条
- **蓄力攻击**：长按 J 蓄力释放范围旋风斩 / 穿透巨型泡泡
- **心之碎片**：散落 3 枚碎片（旧矿道锁门房 / 晨光村锁门小屋 / 雾锁林谜题区），集齐 3 枚生命上限 +1 心
- **钥匙与锁门**：探索地图寻找钥匙，打开藏有宝藏的锁门
- **冰火人式分头解谜**：压力板谜题需要双人分工——一人踩住压力板开门，另一人穿门后在另一侧踩住第二块板，让门保持常开
- **战斗与解谜循环**：每张地图战斗与机关谜题交替推进
- **怪物刷新**：重新进入地图怪物会重生（Boss 例外——击败后永久消失），可反复刷金币与血瓶
- **敌人掉落**：击败敌人有几率掉落血瓶（回复3HP）/ 心心 / 金币

### 章节

1. **序章 · 石门镇**（教学）
2. **第一章 · 旧矿道**（水晶机关 + 双板分头解谜 + 锁门碎片房）
3. **第二章 · 晨光村**（小镇生活 + 支线 + 锁门小屋碎片）
4. **终章 · 雾锁林**（双板谜题 + 菌王三阶段 Boss 战 → 结局）

### 视觉致敬

高饱和复古像素（Sweetie-16）+ 现代径向光照混合 + CRT 扫描线滤镜 + 打字机对话框 + WebAudio 程序化 chiptune 配乐（6 首）

## 技术架构

```
js/
  palette.js   调色板与像素画渲染工具
  sprites.js   全部像素画数据（角色/NPC/敌人/瓦片/道具）
  audio.js     WebAudio 程序化音乐与音效（含音量控制API）
  engine.js    游戏循环 / 输入 / 场景管理 / 缩放
  map.js       瓦片地图 / 碰撞 / 镜头 / 光照 / 压力板联动
  entities.js  玩家双角色（蓄力攻击/分头模式）/ NPC / 敌人AI / 投射物
  battle.js    战斗结算 / 伤害 / 掉落表 / 泡泡麻痹
  dialogue.js  打字机对话 / 剧情脚本（支持 setSolo 分头模式指令）
  ui.js        HUD / 对话框 / 菜单 / 设置界面 / 标题与结局
  story.js     章节场景、谜题布局（压力板联动/锁门钥匙）与剧情数据
  main.js      启动入口 / 状态机 / 设置 / 场景切换
```
