# 雾野列车 (Mistvale Journey)

一款致敬《风来之国》(Eastward) 的像素风 RPG 剧情冒险游戏。
纯 HTML5 Canvas + 原生 JavaScript 实现，零依赖，浏览器直接运行。

## 启动方式

1. 双击 `index.html` 直接游玩；或
2. 本地服务器：`npx http-server -p 8090`（或任意静态服务器）后访问 http://localhost:8090

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| J / Z | 攻击（洛恩：平底锅挥击；小芽：能量泡泡） |
| K / X | 切换角色（洛恩 ⇄ 小芽） |
| E / 空格 / 回车 | 交互 / 对话推进 / 确认 |
| ESC / I | 暂停菜单 |
| F | 全屏 |

## 游戏简介

瘴雾侵蚀大地，人类退入地下石门镇苟延残喘。
沉默的矿工洛恩在矿道深处救下白发女孩小芽——她体内沉睡着能净化瘴雾的「芽光之力」。
隧道塌方的那一夜，两人踏上古老的东行列车，去寻找传说中被雾海淹没的「晴原」。

- **双角色机制**：随时切换洛恩（近战输出）与小芽（远程控制），能力互补解谜
- **4 个章节**：石门镇（教学）→ 旧矿道（地牢战斗）→ 晨光村（小镇生活）→ 雾锁林（Boss 战）
- **视觉致敬**：高饱和复古像素 + 现代光照混合 + CRT 滤镜 + 打字机对话框

## 技术架构

```
js/
  palette.js   调色板与像素画渲染工具
  sprites.js   全部像素画数据（角色/NPC/敌人/瓦片）
  audio.js     WebAudio 程序化 chiptune 音乐与音效
  engine.js    游戏循环 / 输入 / 场景管理 / 光照
  map.js       瓦片地图 / 碰撞 / 镜头
  entities.js  玩家 / NPC / 敌人实体与 AI
  battle.js    战斗结算 / 伤害 / 掉落
  dialogue.js  打字机对话系统 / 剧情脚本
  ui.js        HUD / 对话框 / 菜单 / 标题画面
  story.js     章节场景与剧情数据
  main.js      启动入口
```
